# SP-8.2 Rate-Limit Conformance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `ref:conformance.saturate_op` (a permanently-saturated test tool gated behind `--enable-conformance-tool`) plus a single conformance fixture that triggers `ERR_RATE_LIMITED` (1002) on a single-shot client call, closing the SP-operability-v1 §5.5 (Q5b=i) cross-impl coverage gap.

**Architecture:** One bisect-clean commit. Mirrors the SP-8.1 `ConformanceDeniedTool` pattern exactly — same gate flag, same registration site, same conformance fixture shape. The novel piece is the `Box::leak` of the tool's sole semaphore permit at server startup, making any subsequent client call hit `try_acquire_owned() → Err` and return 1002 deterministically.

**Tech Stack:** Rust 2024. No new dependencies. Reuses `tokio::sync::Semaphore` (already pulled in by SP-operability-v1 C2) and `Box::leak` (`std::boxed`).

**Spec:** `docs/superpowers/specs/2026-04-25-sp-8.2-rate-limit-conformance-design.md`

**Preconditions:** Working tree clean on master; 4-gate green; HEAD at or past `sp-operability-v1` (`e25a394`). Workspace test count 333. Conformance fixture count 32.

- [ ] **Step 2: Append `ConformanceSaturatedTool` struct + impl + Tool impl**

At the end of `crates/atd-ref-server-bin/src/conformance.rs`, BEFORE the existing `#[cfg(test)] mod tests { ... }` block (so the new test goes inside the existing test module), append:

```rust
/// A trivial tool whose semaphore is permanently saturated by the
/// startup-time `Box::leak` in `main.rs`. Every call returns
/// `ERR_RATE_LIMITED` (code 1002) at the dispatch layer's
/// `try_acquire_owned` check, before `call` ever runs.
///
/// If `call` *does* run, that's a bug in the rate-limit gate or in the
/// startup leak — the `InternalError` sentinel makes the violation
/// loud rather than silently succeeding.
pub struct ConformanceSaturatedTool {
    def: ToolDefinition,
}

impl ConformanceSaturatedTool {
    pub fn new() -> Self {
        Self {
            def: ToolDefinition {
                id: "ref:conformance.saturate_op".into(),
                name: "conformance saturate op".into(),
                description:
                    "Test tool: registered with max_concurrent=1, then has \
                     its sole permit leaked at server startup so the \
                     semaphore is permanently empty. Exists only to let \
                     atd-conformance validate the ERR_RATE_LIMITED \
                     (code 1002) wire path. Enabled via \
                     --enable-conformance-tool."
                    .into(),
                version: "0.0.0".into(),
                capability: ToolCapability {
                    domain: "conformance".into(),
                    actions: vec!["saturate_op".into()],
                    tags: vec!["test".into()],
                    intent_examples: vec![],
                },
                input_schema: serde_json::json!({ "type": "object" }),
                output_schema: serde_json::json!({ "type": "object" }),
                bindings: vec![ToolBinding {
                    protocol: BindingProtocol::Cli,
                    config: serde_json::json!({}),
                }],
                safety: ToolSafety {
                    level: SafetyLevel::Read,
                    dry_run: false,
                    side_effects: vec![],
                    data_sensitivity: None,
                },
                resources: ToolResources {
                    timeout_ms: 1000,
                    max_concurrent: 1,
                    rate_limit_per_min: None,
                    estimated_tokens: None,
                },
                trust: ToolTrust {
                    publisher: "atd-ref-server".into(),
                    trust_level: TrustLevel::L0Unverified,
                    signature: None,
                },
                visibility: ToolVisibility::Read,
                required_capabilities: vec![],
                tier: Some(ToolTier::Hot),
            },
        }
    }
}

impl Default for ConformanceSaturatedTool {
    fn default() -> Self {
        Self::new()
    }
}

impl Tool for ConformanceSaturatedTool {
    fn definition(&self) -> &ToolDefinition {
        &self.def
    }

    fn call<'a>(&'a self, _args: serde_json::Value, _ctx: &'a CallContext) -> CallFuture<'a> {
        Box::pin(async {
            Err(ToolCallError::InternalError(
                "ref:conformance.saturate_op was reached by dispatch — \
                 startup permit leak should keep the semaphore empty so \
                 try_acquire_owned() always fails with code 1002"
                    .into(),
            ))
        })
    }
}
```

### 1.3 Add startup-time `Box::leak` to `main.rs`

- [ ] **Step 10: Read current `main.rs` to find the right insertion point**

- [ ] **Step 11: Insert the `Box::leak` block**

Right after the `let registry = builtin_registry(args.enable_conformance_tool);` line (use whatever variable name the file actually uses for the parsed clap struct — could be `args` or `cli`; the plan uses `args`), insert:

```rust
    // SP-8.2: when the conformance tool family is enabled, permanently
    // saturate ref:conformance.saturate_op so the conformance suite's
    // rate-limited fixture sees a 1002 on every single-shot call. The
    // leaked permit lives for the entire process lifetime —
    // intentional, documented, ~64 bytes.
    if args.enable_conformance_tool {
        let entry = registry
            .get("ref:conformance.saturate_op")
            .expect("ref:conformance.saturate_op registered when --enable-conformance-tool is set");
        let permit = entry
            .semaphore
            .clone()
            .try_acquire_owned()
            .expect("saturate_op semaphore should have its single permit available at startup");
        Box::leak(Box::new(permit));
    }
```

If the variable holding the parsed clap struct is `cli` (not `args`), substitute accordingly. Check by looking at the line above — wherever `enable_conformance_tool` is referenced, mirror that name.

- [ ] **Step 12: Verify it compiles**

```bash

```

Expected: clean. If `try_acquire_owned()` doesn't resolve, add `use tokio::sync::Semaphore;` at the top of `main.rs` — but actually `try_acquire_owned` is a method on `Arc<Semaphore>`, so the `Arc::clone` returns `Arc<Semaphore>` and the method is in scope without explicit import. Most likely no new imports needed.

If clippy complains about unused `Box::leak` return value, that's a real warning to silence with a `let _ = Box::leak(Box::new(permit));` or by structuring as `Box::leak(Box::new(permit));` followed by a `let _: ... = ...;`. The simplest form:

```rust
        let _leaked: &'static mut tokio::sync::OwnedSemaphorePermit =
            Box::leak(Box::new(permit));
```

But `Box::leak` returns `&'static mut T` and Rust's "unused value" lints may flag. If clippy fires, add `#[allow(...)]` or use the `let _` form. Address only if clippy actually warns.
